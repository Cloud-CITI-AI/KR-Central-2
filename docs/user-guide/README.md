# User guide

How people use the KR Subdivision Tracker. Wording of buttons and messages follows the product specification
(`docs/spec/PRODUCT_SPEC.md`); if the screen and this guide differ, the screen is right, so tell KR Surveys.

| Guide                                                       | For                                           |
| ----------------------------------------------------------- | --------------------------------------------- |
| [Staff guide](staff-guide.md)                               | KR Surveys staff, KR Admin and administrators |
| [Client and architect guide](client-and-architect-guide.md) | Clients and architects invited to see a job   |

Each job moves through **10 stages and 46 checkpoints**: Preliminaries, WAPC Approval, Western Power, Water Corporation,
Local Government, Busselton Water, WAPC, Survey, Landgate and Titles. A checkpoint is **Completed**, **Not completed** or
**Not required**. The four agency stages (Western Power, Water Corporation, Local Government, Busselton Water) switch to
Not required by themselves when the WAPC Decision Letter has conditions but none for that agency.

Everyone signs in with Microsoft. There are four kinds of access: **admin**, **KR Admin**, **staff** (KR employees) and
**clients and architects**, who see only the jobs KR Surveys gives them. Dates are Australian (for example 28 Sep 2026)
and times are Perth time.

If something looks wrong, note the time, the job number and the **request id** shown on an error page, and send them to
your KR Surveys contact. Do not send client documents or passwords by email.
